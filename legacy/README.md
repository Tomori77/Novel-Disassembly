# 旧版单文件（已归档）

`RP-Disassembly.html` 是最早的单文件版本，代码内没有任何地方引用它，当前版本 `index.html` 已完全覆盖其功能。

## 保留原因

- 历史对照：可查看最初的切分/阅读/导出实现
- 应急：只有一个 HTML 文件时也能打开使用

## 与当前版本的区别

| 能力 | 旧版 | 当前版本 |
|---|---|---|
| 卷/节两级结构 | 无（只有章节） | 有 |
| 通知/请假识别 | 无 | 有 |
| 无用章节/重复检测 | 无 | 有 |
| 标题编辑 | 有 | 有 |
| TXT 导出 | 有 | 有 |
| ZIP / EPUB / 项目目录导出 | 无 | 有 |
| 导出模板与插件 | 无 | 有 |
| IndexedDB 书架 | 无 | 有 |
| 导入 ZIP/文件夹回读 | 无 | 有 |

## 使用

双击 `legacy/RP-Disassembly.html` 即可，无需服务器。导入 TXT 后按正则切分，支持浏览、改标题、导出全部或当前章节。

## 维护

不修复、不新增功能。新需求请改 `index.html` 与 `js/`。确认不需要历史对照后，可整体删除 `legacy/`。
