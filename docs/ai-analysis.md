# AI 分析插件（设计）

## 1. 定位

- 官方插件 `ai-analysis`，**默认启用但空闲**：未配置模型前不发起任何请求，只显示入口与配置。
- 仅手动触发：用户选择范围、看到费用预估、确认后才调用。
- 输出：章节摘要、卷摘要、全书摘要，以及人物/事件/伏笔实体。
- 不改变核心拆解、清洗与 TXT/ZIP/EPUB 导出。

## 2. 配置

预设（OpenAI 兼容）：

| 预设 | Base URL 示例 | 说明 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | 需 key |
| DeepSeek | `https://api.deepseek.com/v1` | 需 key |
| GLM | 用户填写 | 需 key |
| Ollama | `http://127.0.0.1:11434/v1` | 通常无需 key |

初始为空配置：用户选择预设或手填 Base URL、模型名、API Key。Key 只保存在本地 IndexedDB（插件命名空间），不写入仓库、不写入导出文件。

## 3. 触发与流程

```text
选择范围（当前章 / 当前卷 / 全书）
  → 估算 token 与费用
  → 用户确认
  → 分批请求（逐章摘要）
  → 汇总卷摘要
  → 汇总全书摘要
  → 抽取实体（人物/事件/伏笔）
  → 写入插件存储 + 实体词条
```

- 默认模型与并发数可配；并发建议 2–4。
- **MVP 现状**：不并发，按章节顺序执行；无自动重试、费用上限与断点续跑。
- 每章独立任务，记录状态：`pending / running / done / failed / skipped`。
- 失败重试（指数退避，最多 3 次）；可跳过单章继续。
- 支持中断续跑：按章节 id 记录进度。
- 费用上限：达到用户设定的 token/费用阈值立即停止。

## 4. 输入与输出

### 输入

- 单章：标题 + 正文（可截断到 token 上限）
- 卷/全书：不直接塞全文，先逐章摘要，再汇总摘要
- 实体抽取：逐章送正文，要求返回结构化 JSON

### 输出

```js
{
  chapterId: "C00001",
  summary: "100–200 字",
  events: ["……"],
  entities: [
    { entityType: "character", name: "方源", aliases: [], mentions: 3, note: "……" },
    { entityType: "event", name: "开窍大典", chapterId: "C00001", note: "……" },
    { entityType: "foreshadow", name: "春秋蝉", status: "planted", note: "……" }
  ]
}
```

- 章节摘要存插件存储；卷/全书摘要由章节摘要二次生成。
- 实体转为 v2 `entity` 词条，供 JSON/Markdown 导出与后续分析使用。
- 不修改原文、标题、排除状态。

## 5. 费用与隐私

- 调用前显示：预计输入 token、输出 token、按当前模型单价的估算费用。
- 只发送用户选中的章节文本；不上传整本书的元数据（可选发送书名）。
- 提示：第三方 API 会收到文本，可能被用于服务商日志；敏感内容不要使用云端模型。
- CORS：部分服务商禁止浏览器直连；若请求失败，提示改用本地 Ollama 或兼容代理。密钥不经过本项目服务器。

## 6. 存储

- 插件存储（IndexedDB `pluginData`，按 `pluginId` 隔离）：
  - `config`：`{ preset, baseUrl, model, apiKey, skipExcluded }`；
  - `book:<bookId 或 fileName>`：`{ chapters, volumeSummaries, bookSummary, updatedAt }`。
- 章节结果按 `chapterId` 保存，每章完成后立即写入；卷/全书摘要由已有摘要二次生成。
- 实体目前只存在章节结果中，尚未写入 v2 `entity` 词条集合。
- 导出 JSON 时尚未包含实体；Markdown/TXT/ZIP/EPUB 不输出 AI 结果。

## 7. UI

- 侧栏新增“AI 分析”视图：
  - 配置区（预设、Base URL、模型、Key、并发、费用上限）
  - 范围选择与费用预估
  - 任务列表：章节、状态、耗时、token、重试/跳过
  - 结果浏览：摘要、实体列表
- 阅读页提供“生成本章摘要”按钮；卷目录提供“生成本卷摘要”。
- 未配置时按钮禁用并提示配置。

## 8. 失败与边界

- API 返回非 JSON：记录原始片段，标记失败，不污染实体。
- 超时/限流：重试并降低并发；仍失败则跳过。
- 上下文超限：按段落截断，并在摘要中标注“已截断”。
- 用户取消：停止后续批次，保留已完成结果。
- 不自动运行、不在后台偷偷调用。

## 9. 验收

- 未配置时不发请求，导出行为不变。
- 单章摘要成功并持久化，刷新后仍在。
- 全书批处理可停止，保留已完成结果；失败章节记录错误并继续。
- 执行前显示章节数与 token 估算；费用上限尚未实现。
- 实体在 AI 视图可见并持久化；JSON/词条导出尚未接入。
- Key 不出现在导出文件或仓库中（本地 IndexedDB 明文保存）。

## 10. 状态

**已实现（MVP）**：官方插件 `plugins/ai-analysis/`。

### 已实现

- OpenAI 兼容直连：Base URL、模型、API Key、预设；Key 只存插件存储。
- 手动触发，顺序执行：当前章 / 指定卷 / 全书，单次最多 50 章。
- 分析前确认章节数与 token 估算；分析中可停止，保留已完成结果。
- 章节摘要、关键事件、人物/事件/伏笔实体；失败章节记录错误并继续。
- 卷摘要（章节摘要汇总）与全书摘要（优先卷摘要）。
- 结果按书持久化，刷新后保留；支持清空本书结果。
- 401 / 429 / CORS / 超时的可读错误提示。
- 所有正文与摘要使用 `textContent` 渲染，避免 XSS。

### 未实现

- 导出集成：实体尚未写入 v2 词条，也不进入 JSON/Markdown/manifest。
- 并发请求、自动重试与指数退避。
- 成本价格表与费用上限；仅显示 token 估算。
- 断点续跑与逐章重试/跳过按钮。
- 阅读页/卷目录的快捷生成入口（当前只在 AI 分析视图内操作）。
- 请求日志、token 实际用量统计与多模型对比。
